# Triage 标签

技能以五个规范 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签串。

| mattpocock/skills 中的标签 | 本仓库 tracker 的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某角色（如「打 AFK-ready triage 标签」）时，用本表对应的标签串。

保持默认映射：右列 = 左列。打标签严格遵循技能规则，不额外强制任何标签。

## 仓库里的相关标签

除上表五角色外，本仓库另有 `/wayfinder` 用的标签（非 triage 角色，不要混用）：

| 标签 | 用途 |
| --- | --- |
| `wayfinder:map` | 地图 issue：承载 Notes / Decisions-so-far / Fog |
| `wayfinder:research` | 子工单：research 型 |
| `wayfinder:prototype` | 子工单：prototype 型 |
| `wayfinder:grilling` | 子工单：grilling 型 |
| `wayfinder:task` | 子工单：task 型 |
